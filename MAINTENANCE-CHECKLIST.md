# EXA152 Website Maintenance Checklist

Use this checklist about once per month, and after any large site update.

## Listings
- Verify every listing price.
- Verify discount text.
- Verify every direct Eldorado / ZeusX link.
- Confirm listing status: Available / Paused / Hidden.
- Review per-listing delivery estimate.
- Update each listing's `updated` date when you make a meaningful change.

## Workload
- Open `settings.js`.
- Set workload to low / normal / high.
- Update the workload message if needed.
- Review the default paused reason.
- Check the global notice.

## Marketplace
- Confirm Eldorado profile/listings still open correctly.
- Confirm ZeusX profile/listings still open correctly.
- Check that external links open in a new tab.

## Site
- Test homepage search.
- Test game and marketplace filters.
- Test price filter.
- Test sorting.
- Test copy-link buttons.
- Test mobile hamburger menu.
- Test back-to-top button.
- Test 404 page.
- Check the Privacy page.

## Mobile
Test at approximately:
- 360 px
- 390 px
- 430 px
- 768 px

Confirm there is no horizontal scrolling and all buttons remain usable.

## SEO / Search
- Check `sitemap.xml`.
- Check Google Search Console page indexing.
- Check Google Search Console sitemap status.
- Check Bing Webmaster Tools / IndexNow status.
- Request indexing for important newly added pages when needed.

## Analytics
- Review marketplace click events.
- Compare Eldorado vs ZeusX traffic.
- Check which listing pages receive the most traffic.
- Look for pages with traffic but very few marketplace clicks.

## Backups
- Keep the newest known-good ZIP before making large changes.
- Keep at least one older working ZIP as a rollback copy.
