# EXA152 Boosting Website

Free static landing page prepared for GitHub Pages.

## Publish for free with GitHub Pages

1. Create a GitHub repository named `exa152-boosting`.
2. Upload `index.html`, `styles.css`, `robots.txt`, and `sitemap.xml` to the repository root.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Your site will be available at `https://Exa152.github.io/exa152-boosting/`.

## After publishing

- Submit the site URL to Google Search Console.
- Request indexing for the homepage.
- Submit `https://Exa152.github.io/exa152-boosting/sitemap.xml` in Search Console.
- Add the published page link to public profiles you control where promotion is allowed.
- Keep the page useful and accurate; do not keyword-stuff.
